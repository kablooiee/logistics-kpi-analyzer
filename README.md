# Анализатор отчётов

Программа для анализа табличных отчётов из учётных систем.
Рассчитывает ключевые показатели эффективности, формирует
графики и итоговый отчёт в PDF.

## Запуск

pip install -r requirements.txt  
python main.py

## Структура проекта

core/ — логика и расчёты:
  - excel.py — чтение Excel-файлов
  - formulas.py — формулы KPI
  - analyzer.py — анализатор данных
  - reports.py — формирование отчётов (markdown и PDF)
  - charts.py — построение графиков
  - settings.py — настройки программы

ui/ — интерфейс PyQt5:
  - main_window.py — главное окно
  - dialogs.py — диалоговые окна
  - helpers.py — вспомогательные виджеты и функции
  - pages/ — страницы программы

## Использование

1. Открыть программу — python main.py
2. На главной нажать "Данные" и выбрать Excel-файл
3. Использовать разделы программы для анализа
4. Сформировать PDF-отчёт через раздел "Отчёт"
