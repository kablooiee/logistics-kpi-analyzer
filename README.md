# Анализатор логистических данных и KPI

Настольное приложение на Python для анализа эффективности логистических процессов. Программа обрабатывает данные из Excel, рассчитывает ключевые показатели эффективности и помогает выявлять проблемные заявки.

Проект разработан в рамках учебной работы по направлению «Бизнес-информатика».

## Возможности

- Загрузка и обработка логистических данных из Excel.
- Расчёт финансовых, операционных, качественных и временных показателей.
- Анализ данных с помощью графиков и таблиц.
- Выявление аномалий по заданным правилам и пороговым значениям.
- Формирование рекомендаций на основе рассчитанных показателей.
- Создание PDF-отчёта с результатами анализа.

## Используемые технологии

- **Python** — основной язык разработки.
- **PyQt5** — графический интерфейс.
- **pandas и NumPy** — обработка и анализ данных.
- **Matplotlib** — построение графиков.
- **openpyxl** — работа с Excel-файлами.
- **ReportLab** — формирование PDF-отчётов.

## Входные данные и ограничения

Приложение разработано для анализа структурированных логистических данных из Excel. При разработке использовалась таблица с данными о заявках и рейсах, содержащая 84 столбца.

В зависимости от задачи используются, например, следующие поля:

- номер заявки;
- даты подачи, загрузки, разгрузки и закрытия заявки;
- филиал, менеджер и диспетчер;
- сумма заказчика и сумма перевозчика;
- расстояние, фактический и холостой пробег;
- тип перевозчика и причина отмены.

Программа учитывает типы значений: даты и время, числовые показатели и текстовые данные. Она также распознаёт некоторые варианты названий столбцов. Доступность отдельных расчётов зависит от наличия и качества соответствующих данных.

**Приложение не является универсальным инструментом для анализа произвольных таблиц.** При использовании файлов с другой структурой, названиями столбцов или набором показателей может потребоваться изменить сопоставление полей и доработать логику обработки и расчётов.

## Установка и запуск

1. Скачайте или клонируйте репозиторий:

   ```bash
   git clone https://github.com/kablooiee/logistics-kpi-analyzer.git
   cd logistics-kpi-analyzer
   ```

2. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Установите зависимости в Windows:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```powershell
   .\.venv\Scripts\python.exe main.py
   ```

## Использование

1. Запустите программу.
2. В разделе «Данные» выберите Excel-файл подходящей структуры.
3. Изучите рассчитанные показатели, графики и выявленные аномалии.
4. При необходимости сформируйте PDF-отчёт в разделе «Отчёт».
